# newsletter/

El correo de felicitación para clientes: les regalamos la skill y les llevamos a la landing.

## Contenido

- **Asunto y preencabezado.**
- **Saludo:** felicitación de Crowd Digital, breve.
- **El regalo:** qué es la skill y para qué sirve, en dos o tres frases.
- **Botón:** a la landing.
- **Cierre:** firma del equipo.

## Entregables

```
newsletter/
├── correo.md       Texto: asunto, preencabezado y cuerpo
├── correo.html     Versión maquetada
└── correo.txt      Versión en texto plano
```

## Requisitos

- En castellano.
- Un solo mensaje y un solo botón.
- Se tiene que leer bien sin imágenes y en móvil.

**La lista de destinatarios no va en este repo**, que es público. Tampoco nombres de clientes ni resultados del envío.

## Decisiones abiertas

- Herramienta de envío y fecha.
- Si hay una sola versión o varias según el tipo de cliente.
- Quién firma.
